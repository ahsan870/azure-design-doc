Planned service mapping

  • Edge: Global external Application Load Balancer + Cloud CDN + Cloud Armor
  • Private origins: Private Service Connect / internal Application Load Balancer
  • API gateway: Apigee X (private) or API Gateway
  • Compute: 3 private GKE clusters (Autopilot or Standard), GKE Workload Identity Federation
  • Data: Cloud SQL / AlloyDB for PostgreSQL, Firestore or Spanner, Memorystore for Valkey
  • Messaging: Pub/Sub with ordering keys and dead-letter topics
  • Network: Shared VPC hub, Cloud NGFW, Cloud NAT, Cloud DNS, Cloud Interconnect
  • Operations: Cloud Monitoring, Cloud Logging, Cloud Trace, Managed Service for Prometheus
  • Security: Organization policies, VPC Service Controls, Security Command Center, Secret Manager, Cloud KMS
  • Migration: Migrate to Virtual Machines, Database Migration Service, Storage Transfer Service, Google Cloud VMware Engine
